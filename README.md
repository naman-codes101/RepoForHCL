# Student Task Manager (frontend only)

No build step and no server. Open `index.html` in a browser.
Tasks are saved in the browser's localStorage (per browser, per device).

    index.html        page structure
    css/styles.css    responsive layout, light and dark themes
    js/storage.js     load/save tasks in localStorage
    js/app.js         add, edit, delete, complete, filter, sort, search, stats
